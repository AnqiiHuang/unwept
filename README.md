# 欠哭 Unwept

1998 年的民俗悬疑调查游戏。当前可玩范围从开场走到谷家灵堂：孝布辨亲、供桌委托、取到「怀山扶谷雨握笔」，再完成堂前起式和帷后私唱。唱对之后借到门廊的灯，停在出门之前。街窗调查还没有做。

## 启动

```bash
npm install
npx vite --host 127.0.0.1 --port 5173
```

浏览器打开 http://127.0.0.1:5173/ 。第一次点击之后才出声。

生产包：

```bash
npx vite build
npx vite preview --host 127.0.0.1 --port 4173
```

逻辑测试：

```bash
node --experimental-strip-types --test tests/flow.test.ts
```

## 操作

- A / D 或左右方向键走动，也可以点地上的标记，人会走到旁边再查。
- E 查看身边的热点。对话中按空格，或点底部对话框继续。
- 数字键选当前选项。J 打开哭本，I 打开身上的东西，Esc 暂停。
- 对话框固定在底部。有画的人用半身像；还没有正式立绘的人标明「开发占位」。
