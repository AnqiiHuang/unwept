# 还缺的素材

场景、道具和大部分声音仍是程序绘制或合成音。缺的地方标着「开发占位」，没有拿别的图顶上，也没有把旧画拉宽。人物剪裁说明另见 `docs/CHARACTER_ART.md`。

下面按对当前试玩的影响从高到低排。试玩停在街窗结尾，传桶的人和井仍在画外。

## 先补这些，试玩的判断才不像临时图

- 街窗三处近看。现在是同一套临时画面（`开发占位 · 近看`）：灶门两下短火星对一条长哭腔，窗左被角起、落、再起，床头先是被木棂截开的亮边、再看才露出饭碗，收起自己的碗后窗里的水纹仍跟着哭腔。时间关系能看出来，但不是正式近景。需要：灶门火星、窗左被角、床头木棂与饭碗、碗上水纹、睡着的两个人和闭着的嘴。
- 新坳街本身。灶门、秤、窗左、床头凳现在是按位置放的色块，不是正式街道。近看盖住了画面中央，走路时仍能看出是占位。
- 这几段声音：灶门爆裂、窗后哭腔、水纹、桶耳碰木。现在是短合成音。音量关到零时，判断靠方位字幕和上面的临时画面，不靠这些声音。

## 接着补，走路和说话会顺一些

- 小满的侧面：双脚并拢的空手站立、提箱走路、端碗走路、提灯、按喉。站住又提着箱时用了临时站姿。走路端碗还没有三帧，暂时把瓷碗放在腰前的手上。借到灯之后，灯画在身侧。
- 对话半身像。桂芬、杜长贵、谷建军只有正面，侧面和递布、坐在船边、隔着衣服按钥匙都没有。谷秀兰没有半身像，棺前用色块，标着「开发占位」。谷雨没有不带木柱的蹲听。
- 灵堂、村口的正式背景。库边要补的分层写在上面。开场三张静帧是参考，不是最终分镜，也不拿来铺库边。
