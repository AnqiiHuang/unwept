# 还缺的素材

场景、道具和大部分声音仍是程序绘制或合成音。缺的地方在画面上留着占位，没有拿别的图顶上。人物剪裁说明另见 `docs/CHARACTER_ART.md`。

## 人物

- 谷秀兰没有半身像。棺前两句对白用色块，标着「开发占位」。
- 桂芬、杜长贵、谷建军只有正面。侧面、递布、坐在船边刮泥、隔着衣服按钥匙，都还没有。
- 小满没有双脚并拢的侧面站立，也没有端碗走路、按喉、提灯的侧面。走路时碗是一枚小瓷碗图形。
- 谷雨没有不带木柱的蹲听。
- 周启明、年长女性和白褂记录者已剪出，这一轮不出场。

## 场景和道具

- 灵堂、库边、村口是色块和剪影，不是正式背景。
- 灯芯、提灯、十九条旧布、作业本、粉笔、竹片、裹锣都是示意，不是道具图。
- 街窗、窗根和门外坐着的人还没有画。下一轮才会用到。

## 声音

方向字幕在。音量关到零时字幕仍在。下面这些还不是正式录音：

- 刮泥、瓷器、水纹、喝水、倒水、风、唱、续腔、布、钥匙：短合成音。
- 灯芯并成一股、街外那一声哭：这一轮新加的合成音，不是人声。
- 误选时碗沿的两道急纹只有字幕，没有单独的一声。
