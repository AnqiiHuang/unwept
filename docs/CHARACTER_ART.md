# 人物素材检查

四张图都是带透明底的设定板，分辨率约 1024 宽。整张不能当作一个角色贴进场景。下面按「谁、哪一块能剪、哪一块还要画」分开。游戏里现在用的是剪出来的单人图：场景人在 `public/characters/scene/`，对话半身在 `public/characters/portrait/`。原图留在 `02_美术参考/人物/设定参考/`。剪出来但这一轮不放进画面的，在 `02_美术参考/人物/可裁切暂缓/`。

人物按同一套身高对齐：成人场景高 360，谷雨按孩童比例为 274。半身都取站立图上半身，避免特写脸和半身像混用后头显得忽大忽小。小满、谷雨用侧面；桂芬、长贵、建军目前只有正面，先以正面单人剪影站在场景里，侧面还要补。

## 谷雨多视图

红毛衣、双辫、牛仔裤。抱着作业本，又有蹲听，对得上谷雨。

| 部位 | 处理 |
| --- | --- |
| 右侧全身侧面 | 已用于场景。朝右，空着手。 |
| 正面全身的上半身 | 已用于对话半身。 |
| 背面、抱作业本、席地而坐 | 已剪出，暂不进游戏。抱书和坐姿不是这一轮的站立动作。 |
| 蹲在木柱旁 | 人和柱子连在一起，柱边还有红边。不能当单人剪影。蹲听要另画，不要这根柱。 |

## 余小满转面与表情

盘发、蓝布对襟、手里是哭箱。这是小满，不是阵容里那个系围裙的人。

| 部位 | 处理 |
| --- | --- |
| 正面全身的上半身 | 已用于对话半身。箱子在手下，没有切进半身。 |
| 侧面、四分之三、背面 | 手里都提着箱。场景里的箱子是单独的热点，用这几张会叠出两个箱子。已另存侧面提箱，等「人箱一体」的走法再接。 |
| 四张脸：平视、侧脸、含泪、闭眼 | 能剪，但是特写。和半身像放在同一个对话框里，头会突然变大。先留着，不进默认对白。含泪、闭眼等真正哭的句子再用。 |

## 余小满动作板

同一套蓝布衫。上面一排是空着手的侧面走路，中间和下面换了角度。

| 部位 | 处理 |
| --- | --- |
| 三个朝右的走步 | 已用于场景。停下时停在第一步，因为没有双脚并拢的侧面站立。 |
| 端碗 | 站住、手里有碗时换这张。走路时还没有端碗的侧面，碗用小瓷碗图形跟着走。端碗走路要补。 |
| 正面站立、提箱、按喉、提灯、伸手、低头看碗、鞠躬 | 角度和走路不一致，或是这一轮用不到的动作。已剪出留底，不贴进场景。按喉、提灯、鞠躬都还没有侧面。 |

## 还要补的侧面

同一身衣服、同一画风，不要另起一套：

- 小满：双脚并拢的侧面站立；端着碗走路；不提箱的侧面停步；按喉的侧面。
- 谷雨：不带木柱的蹲听。
- 桂芬、长贵、建军：朝右的侧面全身。长贵要能坐在船边，建军要能按着钥匙，桂芬要能递布。
- 表情特写如果要进对话框，要和现在的半身用同一头身比例重剪，不能直接放大脸。
